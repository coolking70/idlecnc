# Stage 8.2G-C.1.1 Delivery

This closure hardens runtime readability and visual route clearance without
changing combat authority, planner footprints, engagement legality, or report
semantics.

```sh
npm run test:stage8-2G-C-1-1
npm run browser:stage8-2G-C-1-1
npm run build:stage8-2G-C-1-1
npm run verify:stage8-2G-C-1-1
```

The independent audit JSON is a previous-review baseline only. It is not
loaded by production code, and failed samples are retained rather than
filtered. Browser evidence is generated from the current renderer and binds
the seven screenshots to recomputed state, final CSS-pixel metrics, route
clearance, timestamps, and PNG hashes.
